## 本人有话要说

鉴于本博客从搭建到改字体，均有 AI 出没，现有必要说明：作者目前仍为人类。

判断依据是，AI 不需要吃饭，我需要。而且我刚吃过。

至于独立思考，本人一直在坚持。比如 AI 给出两个方案，我会独立选择第一个。它问要不要继续，我也会亲自回复“继续”。

**这些参与，请不要忽略。**

## 事情是这样的

以前我想学点什么，先搜资料，再看教程，然后被一个教程作者认为“不言自明”的步骤卡住。

现在我把问题丢给 AI。它装依赖，改代码，修报错，很快给我一个能运行的东西。我看了一眼效果，满意地点了点头。

接下来，只要没人问原理，我就已经学会了。

偏偏我自己想问。

> “这里为什么这么写？”
>
> “很简单，我们只需要……”
>
> “停，就从‘只需要’这里开始讲。”

于是事情做完以后，还得聊好一会儿。有时候让它举个例子，有时候自己改两行试试。改坏了也挺好，至少这次报错有我的功劳。

### 以下行为可证明本人尚在动脑

- 看见一段代码，能指出自己不懂哪行。
- AI 说没问题，我觉得不对，再查一查。
- 同一个问题问了两遍，第二遍换了个说法。
- 对着讲解点头以后，发现自己根本复述不出来。

最后一条证据比较充分，经常出现。

### 关于“正在蒸馏 AI”

这个博客取了这么个标题，听着像我有什么技术。

实际操作如下：

1. 问它一个问题。
2. 让它讲得再明白点。
3. 写进笔记。
4. 隔几天翻笔记。

暂时没有 GPU，也没有训练集。只有一个聊天窗口，和一个记性不太好的我。

## 把现场留下来

这篇文章也顺便试试 Markdown 排版。以后写 JavaScript、TypeScript、API，不用先担心中文和 English 放在一起长什么样。

标点也来报个到：“这个会了吗？”「会了。」（真的吗？）……先保留意见——毕竟还没关掉答案。

当前掌握程度：~~熟练运用~~ _看着讲解能跟上_。**下次试试自己做。**

### 一段非常诚实的 TypeScript

```typescript
const learning = {
  projectWorks: true,
  understood: false,
  nextQuestion: "这个函数又是干嘛的？",
};

console.log(learning.nextQuestion);
```

`projectWorks` 和 `understood` 分开写，是因为这两个值经常不一样。至于 `git diff`，我会用它看看 AI 刚才改了哪些文件。总得知道自己点了什么同意。

```bash
# 这条我现在会自己敲了
pnpm dev
```

### 本人参与情况公示

| 环节   | AI 做了什么    | 我做了什么                     |
| ------ | -------------- | ------------------------------ |
| 搭博客 | 写代码、装依赖 | 说想要什么样的                 |
| 改排版 | 改样式         | 说这里不好看                   |
| 讲原理 | 解释一遍       | 让它再解释一遍                 |
| 写笔记 | 帮忙整理       | 检查有没有我没懂却写懂了的地方 |
| 休息   | 等下一条消息   | 真去休息                       |
